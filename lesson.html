How to check the links in a web page file with Python

Short answer

A web page can look fine while some of its links go nowhere. This lesson builds a small read-only Python tool that reads one HTML file and reports links with an empty address, links to a file that is not in the page folder, links to a #place that has no matching id on the same page, and id values used more than once. It does not open web addresses, so it cannot say whether one still works. It shows how many problems it found and the first five of each kind.

Follow along and build it step by step. You add each file yourself, run each command, and see the real recorded result.

Common mistakes

  1. Listing links and calling it checked. The first version in this lesson prints every link address and says nothing about whether any of them leads anywhere.
  2. Assuming a web address was tested. The tool counts web addresses but never opens them, so it cannot tell you whether one still works.
  3. Forgetting that places on a page need an id. A link such as #pricing only works if some tag on the same page has the id pricing. The tool compares them exactly, capitals included.
  4. Treating a pass as proof the page is right. These checks look at the links in the file, not what the page says or how it looks. Images, scripts and links added by JavaScript are not read.

Frequently asked questions

How do I check the links in an HTML file with Python?

Read the file with the html.parser module, collect the href of every a tag and the id of every tag, then look for each linked file and each #place. This lesson builds a small tool that does that.

Will this change my page?

No. The tool only reads the file. A test checks that one small test page has the same bytes and the same modified time before and after a run. That is the only evidence for this claim.

Does it test web addresses?

No. It counts addresses starting with http or https, other schemes such as mailto, and addresses starting with a slash, and says they were not checked. It has no code that opens a network connection.

Does it list every problem?

It counts every problem of the kinds it checks, but shows only the first five examples of each kind.

What about broken HTML?

The Python documentation says the HTML parser can parse invalid markup, so a page with broken HTML is read without complaint. The tool does not say the HTML is valid.

Does it check images, scripts and stylesheets?

No. It reads only a tags. A base tag is ignored. Links added by JavaScript are not seen because the tool never runs the page.
